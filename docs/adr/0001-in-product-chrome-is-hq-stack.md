# In-product chrome is the HQ stack

Jev used to sample three exclusive shells (sidebar / icon-rail / topbar) from shadcn dashboard-01. Maple HQ always stacks four regions: icon rail + pages sidebar + top bar + page bar. We copied that stack into this catalog and reduced the nav slot to the two states HQ actually has — pages sidebar pinned vs collapsed.

Keeping the exclusive shells would have been faster and more varied, and would never have looked like HQ. Sampling a fake third HQ mode (no top bar, icon-rail-only) was rejected because it is not a shipped HQ state.
